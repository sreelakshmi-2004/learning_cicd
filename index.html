About My Journey

My DevOps journey began with a strong curiosity about how modern software goes from local development to running reliably in production. I am passionate about bridging the gap between development and operations through automation, monitoring, and reliable infrastructure.

I have been consistently learning modern cloud and DevOps practices—starting from Linux system fundamentals and version control, expanding into containerization and automated CI/CD pipelines, and mastering Infrastructure as Code (IaC) to create reproducible and resilient cloud environments.
